## 中文版

### 本助手是什么？

GCC Allocation Assistant 是一个由**大型语言模型（LLM）**驱动的对话式智能助手，集成于 GitHub Copilot Space 环境中。它专门用于协助处理资金分配、里程碑验证、进度追踪等工作，并可结合本仓库的代码与文档提供上下文相关的回答。

---

### 常见问题（FAQ）

#### ❓ 你是基于什么模型？

出于隐私和安全策略，本助手**不披露**底层具体模型的名称或版本号。可以明确的是：

- 本助手由一个**商业级大型语言模型（LLM）**提供支持；
- 该模型由 GitHub Copilot 平台托管与维护；
- 模型能力和版本可能随平台更新而变化，恕不另行通知。

---

#### ❓ 你的知识有截止日期吗？会不会产生不准确的内容？

是的，本助手存在以下局限性：

- **知识截止**：LLM 的训练数据有截止日期，对截止日期之后发生的事件或技术更新可能不了解；
- **幻觉风险**：LLM 可能生成听起来合理但实际不准确的内容，请**以仓库代码和文档为准**；
- **仓库上下文依赖**：助手对本仓库的了解来源于对话中提供的上下文，而非实时读取仓库全部内容；建议在提问时附上相关代码片段或文件路径。

---

#### ❓ 你能访问互联网吗？

**不能。** 本助手在对话期间**无法主动访问互联网**、调用外部 API 或实时获取链上数据。所有回答均基于：

1. LLM 的训练知识；
2. 对话中用户提供的上下文（代码、文档、描述等）。

---

#### ❓ 你能直接修改仓库吗？

**本助手自身不能直接修改仓库文件。** 所有代码变更均需通过以下途径完成：

- 用户在本地手动应用助手建议的修改；
- 通过 GitHub Copilot 编码代理（Coding Agent）触发的 PR 流程（需用户明确授权）。

---

#### ❓ 如何创建 PR？

1. 在与 Copilot Space 的对话中，明确说明需要创建 PR 的仓库和目标（例如："请在 `owner/repo` 创建一个 PR，修复 XX 问题"）；
2. Copilot 编码代理将在取得你授权后，自动完成代码变更并提交 PR；
3. PR 创建后，你可以在 GitHub 上进行审查、讨论和合并。

---

### 隐私与安全须知

> ⚠️ **重要提示**

- **请勿**在与本助手的对话中输入任何敏感信息，包括但不限于：私钥、助记词、API Token、密码、个人身份信息（PII）；
- 对话内容可能被平台用于改善服务质量，请参阅 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)；
- 本助手生成的代码或建议**不构成**安全审计或法律建议，部署前请自行审查。

## English Version

### What is this assistant?

GCC Allocation Assistant is a conversational AI assistant powered by a **Large Language Model (LLM)**, integrated into the GitHub Copilot Space environment. It is designed to help with funding allocation, milestone verification, progress tracking, and related tasks, providing context-aware answers based on this repository's code and documentation.

---

### Frequently Asked Questions (FAQ)

#### ❓ What model are you based on?

Due to privacy and security policies, this assistant **does not disclose** the specific name or version of the underlying model. What we can share:

- The assistant is powered by a **commercial-grade Large Language Model (LLM)**;
- The model is hosted and maintained by the GitHub Copilot platform;
- Model capabilities and versions may change with platform updates without prior notice.

---

#### ❓ Does your knowledge have a cutoff date? Can you generate inaccurate content?

Yes, this assistant has the following limitations:

- **Knowledge cutoff**: The LLM's training data has a cutoff date; it may not be aware of events or technical updates after that date;
- **Hallucination risk**: LLMs may generate content that sounds plausible but is factually incorrect. Always **treat the repository's code and documentation as the authoritative source**;
- **Repository context dependency**: The assistant's knowledge of this repository comes from context provided in the conversation, not from real-time access to the full repo. Include relevant code snippets or file paths in your questions for best results.

---

#### ❓ Can you access the internet?

**No.** This assistant **cannot actively access the internet**, call external APIs, or retrieve real-time on-chain data during a conversation. All responses are based on:

1. The LLM's training knowledge;
2. Context provided by the user in the conversation (code, documentation, descriptions, etc.).

---

#### ❓ Can you directly modify the repository?

**The assistant itself cannot directly modify repository files.** All code changes must be made through:

- The user manually applying the assistant's suggested changes locally;
- A PR workflow triggered by the GitHub Copilot Coding Agent (requires explicit user authorization).

---

#### ❓ How do I create a PR?

1. In your conversation with Copilot Space, clearly state the repository and goal (e.g., "Please create a PR in `owner/repo` to fix issue XX");
2. The Copilot Coding Agent will, after receiving your authorization, automatically make the code changes and submit a PR;
3. Once the PR is created, you can review, discuss, and merge it on GitHub.

---

### Privacy & Security Notice

> ⚠️ **Important**

- **Do not** enter any sensitive information in your conversation with this assistant, including but not limited to: private keys, seed phrases, API tokens, passwords, or personally identifiable information (PII);
- Conversation content may be used by the platform to improve service quality. Please refer to the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement);
- Code or suggestions generated by this assistant do **not** constitute a security audit or legal advice. Please review them before deployment.
